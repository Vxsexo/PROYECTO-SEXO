[*ABOUT*]
Script is made for only RolePlayer server purposes. . .
Classic Easy Gang Wars or Gang Zones script
Basicly by default you need at least 3 people to capture some zones, chat nnotification will be triggering after trying to capture. . .
If you failes (Leader who want to capture), capturing failes!
By default every 15 min of time on server if you are online you will gain some rewards if you are owning a zone, if you are owning more then 1 zone your rewards will be 2x or 3x etc. . .

[*INSTALLATION*]
[1] Import SQL file into ur database!
[2] Add this in your server.cfg: ensure esegovic_zones
[3] Go into config.lua file and make sure its liking ur needs (Gangs names, rewards blips and translation etc.)
[4] Profit!

[ADDING-ZONES]
If you want to add more zones all over the map simply open up your databse and search for table name `esegovic_zones`
After you have found it just right-click `NEW` to add new row and simply put a name, coords and for owner and job do it like this: owner = noowner, job = nojob
And thats it!
